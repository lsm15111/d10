| 고객 회원가입 · 로그인 · 로그아웃 | 검증 | pytest, 브라우저: 중복 이메일 · 비밀번호 틀림 · 로그인 뒤 원래 화면으로 |
| 업체 회원가입 (기본 회원정보 + 사업자등록증만) | 검증 | pytest, 브라우저: 가입 → 업체 홈 '승인 대기' |
| 관리자 업체 승인 · 반려 (사유 필수) | 검증 | pytest, 브라우저: 빈 사유 거부 → 반려 → 업체 홈에 사유 → 승인 |
| 마이페이지: 내 프로젝트 · 내 정보 · 설정, 계정 메뉴(이름 · 이메일) | 검증 | 브라우저 1280px · 360px (가로 스크롤 없음) |
| 회원 탈퇴 (진행 중이어도 가능, 비밀번호 다시 확인) | 검증 | pytest, 브라우저: 틀린 비밀번호 → 탈퇴 → 프로젝트 · 사진 · 디스크 파일까지 지워짐 |
| 견적 받기 → 사진 · 도면 올리기 → 프로젝트 만들기 (도배 유형 포함) | 검증 | pytest, 브라우저 |
| 사진 위치 정보(GPS) · EXIF 지우기, 회전 반영, HEIC → JPEG | 검증 | pytest (GPS 넣은 사진 → 저장본에 EXIF 없음) |
| 내 프로젝트 카드: 공정별 상태 한 줄 + 할 일 버튼 하나 | 검증 | 브라우저 (실제 프로젝트 · 예시 프로젝트) |
| 업체 정보 출처별 보이기 (믿집 확인 · 업체가 적은 정보 · 믿집 기록), 전화번호 숨김 | 검증 | 브라우저 (예시 업체) |
| 요청 입구 보호: 본문 한도, 같은 오류 모양, DB 장애 503, 요청 제한, 동시 요청 409 | 검증 | pytest `test_guards.py` |
| migration 0001 → 0006 | 검증 | `docker compose run --rm migrate`, `alembic check` 차이 없음, 테스트에서 up → down → up |
| 운영 설정: Caddy 본문 한도 · 타임아웃 · 헬스체크, uvicorn 프로세스 2개 | 구현 | `caddy validate`, `docker compose config` (실제 EC2 배포는 안 함) |
| CI (`.github/workflows/ci.yml`) | 구현 | YAML 읽기 · 각 명령을 로컬에서 같은 순서로 돌림. GitHub에서는 아직 안 돎 |
