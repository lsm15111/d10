# 개인정보 · 업체 정보 규칙

기준일 2026-10-29 · 상태: 팀 규칙 (예전 AGENTS.md 5장을 옮겼다)

AGENTS.md는 구조 · 흐름 · 검증 규칙만 두기로 해서, 개인정보와 업체 정보 규칙은 이 문서에 둔다. 화면별 공개 시점은 [mypage-vendor-info.md](mypage-vendor-info.md) 4.4가 자세하다.

## 고객 정보

- 실측이 확정되기 전에는 업체에 시 · 군 · 구, 평형, 공정, 희망 시기까지만 보인다. 사진 · 도면 · 준공 연도 · 예산을 가견적 단계에서 보일지는 mypage-vendor-info.md 7장 7번에서 정한다.
- 동 · 호수와 연락처는 실측이 확정되고 고객이 동의한 뒤 그 업체에만 보인다. 실측 확정은 업체가 실측 요청을 '확인'한 때다.
- 고객과 업체는 안심번호로 연락한다. 실제 번호와 상세 주소는 암호화해 저장한다.
- 이름, 전화번호, 상세 주소, 이메일은 로그, 추적, 프롬프트, 오류 메시지에 넣지 않는다. 꼭 필요하면 가린 값을 쓴다.
  - 지금 지키는 곳: DB 오류 메시지에 SQL 값을 넣지 않는다(`app/db.py` hide_parameters), 처리하지 못한 오류는 종류와 위치만 남긴다(`app/shared/request_guards.py`), 입력값을 오류 응답에 되돌려 보내지 않는다(`app/shared/errors.py`).
- 올린 사진은 저장하기 전에 위치(GPS) · EXIF를 지운다(`app/files/images.py`).
- 회원 탈퇴는 진행 중인 프로젝트가 있어도 막지 않고, 지우는 것을 한 화면에 보인 뒤 비밀번호를 다시 받는다 (개인정보 보호법 제38조④).

## 업체 정보

- 업체는 가입할 때 기본 회원정보와 사업자등록증만 낸다. 관리자가 등록증을 보고 승인해야 목록 · 추천 · 업체 기능에 나온다(FBF-01, FAD-02).
- 승인 · 반려는 누가 언제 했는지와 반려 사유를 남긴다. 사업자등록증 파일은 관리자와 그 업체만 본다.
- 상호 · 사업자번호 · 공정 · 시공 지역 같은 업체 정보는 승인 뒤 업체 정보 관리(FFV-08)에서 받는다.

## 데모 · 테스트 데이터

- 테스트 · 시드 · 데모 데이터는 합성 데이터만 쓴다. 실제 업체 이름을 동의 없이 쓰지 않는다.
- 데모 프로젝트에는 화면에 '예시'를 붙인다.
