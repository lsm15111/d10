# 0002. 가견적서 · 실측 견적서는 업체가 써서 낸다

- 상태: 결정 (2026-10-29)
- 결정한 사람: PO
- 바꾸는 것: ADR 0001 '맥락'의 에이전트 목록 중 '가견적 설명'

## 맥락

요구사항 정의서 v3.2(2026.10.29)는 업체가 직접 가입하고(FFV-01), 승인된 업체가 가견적서(FFV-03)와 실측 견적서(FFV-05)를 써서 내며, 제출 즉시 고객 프로젝트에 등록된다고 정한다. 그런데 AGENTS.md 1장은 가견적을 "업체 단가표 × 표준 수량으로 믿집이 계산한 견적"으로, 에이전트 범위를 "업체 추천 · 가견적서 · 공정표"로 적고 있었다. v3.2의 AI 기능은 FAG-01 예상 공정표, FAG-02 추천 업체 선정, FAG-03 확정 공정표다.

## 결정

- 가견적서와 실측 견적서는 **업체가 써서 낸다.** 믿집은 견적을 대신 만들지 않는다.
- 믿집이 계산해서 보여 주는 금액은 **공공 기준 표준견적서**뿐이다. 비교 기준이고 업체 견적이 아니다.
- 견적서 양식은 **표준 행 양식**이다. 공정별 표준 행마다 업체가 금액과 포함 상태(포함 · 묶음 포함 · 따로 계산 · 선택 · 실측 후 · 안 함)를 적고, 없는 항목은 줄을 더한다. 합계 · 부가세는 서버 계산 엔진이 만든다.
- 에이전트는 셋: 예상 공정표, 추천 업체 선정, 확정 공정표. 가견적서 에이전트는 두지 않는다.
- 업체 단가표(`price_book`)는 1차 범위에서 뺀다.

## 다른 안

- 믿집이 업체 단가표로 가견적을 계산: 업체가 단가표를 먼저 채워야 하고, 요구사항과 다르다.
- 총액 + 파일 첨부만 받는 자유 양식: 업체는 편하지만 FFW-11 비교표에서 같은 줄끼리 맞출 수 없다.

## 결과

- AGENTS.md 1장(흐름 · 용어 · 에이전트 범위), 3장(업체 입력 금액과 합계), 4장(에이전트 이름 · eval 세트), 5장(업체 승인), 7장(패키지 목록)을 고쳤다.
- 업체 화면(견적 요청함, 가견적서 쓰기, 실측 견적서 쓰기, 공사기간)이 1차 범위에 들어온다.
- 견적 줄 저장 규칙(표준 행 키 + 포함 상태 6종)은 그대로 쓴다.
